# Attribution and license

This plugin is based on the BDSP transport and protocol tooling from
[Decryptu/pokeldn](https://github.com/Decryptu/pokeldn).
The bundled `bdsp_connect.py` is a modified version of that project's transport.
Changes add Diglett contributions, bounded delivery, periodic renewal, session
filtering and status callbacks. The remaining plugin files implement registration,
configuration, capture summaries, packaging and tests.
